SKILL.md Inspector provides live diagnostics for every file named exactly SKILL.md in offline mode, guided quick fixes, detailed reports, and workspace-wide checks for naming and scope conflicts. All checks use deterministic static analysis, documented compatibility rules, and configurable heuristics. The extension does not run skills against an agent, so its findings are review guidance—not proof that a skill will be selected, executed correctly, or behave consistently across agent platforms.
