CheckFlexLMLicenseStatus is a small C# utility for checking FlexLM license expiration
status. It calls `lmutil`, reads license-server output, and exposes the result through
a local self-hosted Web API endpoint for simple integration with monitoring tools.

[[Go to project]](https://github.com/Krusty84/CheckFlexLMLicenseStatus)
